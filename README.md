🌍 Слово Современное приложение для изучения иностранных языков, помогающее пользователям расширять словарный запас, тренировать грамматику и отслеживать свой прогресс в интерактивном формате.✨ Основные возможности📚 Интерактивные уроки и карточки (Flashcards): изучение новых слов и фраз с переводом, транскрипцией и примерами использования.🧠 Система интервального повторения (Spaced Repetition): умный алгоритм напоминаний для эффективного запоминания лексики.🎯 Практические упражнения и тесты: задания на аудирование, правописание, подбор перевода и составление предложений.📈 Отслеживание прогресса: статистика изученных слов, ежедневные цели (стрики) и уровни владения языком.👤 Личный профиль: сохранение прогресса, настройка языка интерфейса и изучаемого языка.🛠 Технологический стекЗамените или дополните список технологий в соответствии с вашим проектом:Frontend / Mobile: [например: React / React Native / Flutter / Swift / Kotlin]Backend: [например: Node.js (Express / NestJS) / Python (FastAPI / Django) / Go]База данных: [например: PostgreSQL / MongoDB / Firebase / SQLite]Аутентификация: [например: JWT / OAuth 2.0 / Firebase Auth]Дополнительно: [например: Docker, Redux / Zustand, Tailwind CSS, Text-to-Speech API]📁 Структура проектаlanguageLearningApp/
