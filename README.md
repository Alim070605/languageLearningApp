# Слово
Современное приложение для изучения иностранных языков, помогающее пользователям расширять словарный запас, тренировать грамматику и отслеживать свой прогресс в интерактивном формате.

---

## ✨ Основные возможности

- 📚 **Интерактивные уроки и карточки (Flashcards):** изучение новых слов и фраз с переводом, транскрипцией и примерами использования.
- 🧠 **Система интервального повторения (Spaced Repetition):** умный алгоритм напоминаний для эффективного запоминания лексики.
- 🎯 **Практические упражнения и тесты:** задания на аудирование, правописание, подбор перевода и составление предложений.
- 📈 **Отслеживание прогресса:** статистика изученных слов, ежедневные цели (стрики) и уровни владения языком.
- 👤 **Личный профиль:** сохранение прогресса, настройка языка интерфейса и изучаемого языка.

## 🚀 Быстрый старт

### Предварительные требования

Убедитесь, что у вас установлены:
- [Git](https://git-scm.com/)
- `[Node.js >= 18.x / Python >= 3.10 / Flutter SDK — укажите нужное]`

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Alim070605/languageLearningApp.git
   cd languageLearningApp
   ```

2. **Установите зависимости:**
   ```bash
   # Для Node.js / React / React Native:
   npm install

   # Или для Python:
   # pip install -r requirements.txt

   # Или для Flutter:
   # flutter pub get
   ```

3. **Настройте переменные окружения:**
   Скопируйте файл `.env.example` в `.env` и заполните необходимые ключи:
   ```bash
   cp .env.example .env
   ```

4. **Запустите проект:**
   ```bash
   npm start
   ```
